description: Quy tắc chung cho dự án Đồng hồ thông minh Xe điện ESP32-S3

Project Context & Hardware Rules
1. Hardware Architecture
MCU: ESP32-S3 (8MB Flash / 8MB PSRAM)

Display: OLED 0.91/0.96 inch I2C (SSD1306, Resolution: 128x32 or 128x64)

RTC: DS3231 (I2C)

Motor Controller: Votol EM150sp (UART1)

BMS: ANT BMS (UART2)

2. Pinout Configuration
I2C (OLED + RTC): SDA = GPIO 9, SCL = GPIO 8

UART1 (Votol): TX = GPIO 17, RX = GPIO 18 (Baudrate: 115200)

UART2 (ANT BMS): TX = GPIO 15, RX = GPIO 16 (Baudrate: 19200)

Buttons: BTN_SET = GPIO 4, BTN_UP = GPIO 5, BTN_DOWN = GPIO 6 (INPUT_PULLUP)

3. Coding Standards
Sử dụng PlatformIO với C++ Arduino Framework.

Mọi hàm đọc UART phải sử dụng cơ chế Non-blocking (không dùng delay blocking).

Sử dụng FreeRTOS Task:

Core 0: Đọc dữ liệu UART (Votol, BMS) & Bluetooth/Android Auto.

Core 1: Quản lý giao diện OLED (Render 20-30FPS) và đọc nút bấm.

Tất cả struct chứa dữ liệu sensor/UART phải được bảo vệ bằng Mutex hoặc dùng biến volatile.
